# 🇧🇷 Português (BR)

Programa para Windows que permite **abrir várias contas do Roblox ao mesmo tempo** no mesmo PC, de forma simples, com interface moderna (tema claro/escuro).

## ⬇️ Como baixar

Vá em **[Releases](https://github.com/gatosmias1/Roblox-Multi-Account-Manager/releases/latest)** e baixe **um** destes arquivos:

| Arquivo | Para quê |
|---|---|
| `Roblox-Multi-Account-Manager-Setup.exe` | **Instalador.** Instala no Windows com atalhos e desinstalador. Instala só para o seu usuário (não pede administrador). |
| `Roblox-Multi-Account-Manager-Portable.exe` | **Portátil.** Não instala nada: é só abrir, de qualquer pasta ou pendrive. |

Os dois são o mesmo programa e usam os mesmos dados.

## ✨ Recursos

- **Multi-instance:** abre quantas contas você quiser ao mesmo tempo.
- **Login pelo site oficial, sem instalar nada:** abre o Microsoft Edge (ou Chrome) numa janela temporária, você loga normalmente e o cookie é capturado automaticamente.
- **Cookies protegidos:** ficam criptografados com o Windows (DPAPI) neste PC.
- **Jogos:** busque por nome ou ID, use jogos recentes e favoritos, e informe o Job ID para entrar num servidor específico.
- **Intervalo entre contas:** os segundos são salvos automaticamente.
- **Grupos de contas:** inicie várias contas com um clique.
- **Status em tempo real:** Online, Offline ou Em jogo, atualizado rapidamente.
- **Apelidos e cores** para identificar cada conta.
- **Iniciar com o Windows** (opcionalmente já minimizado na bandeja).
- **Bandeja do sistema** e **senha opcional** para abrir o programa.
- **Idioma automático:** Português ou English, conforme o seu Windows (dá para trocar em *Preferências*).
- **Atualização automática:** avisa quando há versão nova nas Releases e instala sozinho.

## 🧩 Requisitos

- Windows 10 ou 11 (64 bits).
- Roblox instalado **pelo site roblox.com** (não pela Microsoft Store).
- Microsoft Edge (já vem no Windows) ou Google Chrome, só para o login pelo site.

## 🚀 Como usar

1. Abra o programa e clique em **Login pelo site** (ou **Adicionar cookie**).
2. Entre na conta na janela que abrir. Ela fecha sozinha ao terminar. Repita para cada conta.
3. Marque as contas que quer abrir.
4. (Opcional) Digite o nome ou ID do jogo e, se quiser, o Job ID.
5. Clique em **Iniciar**. **Mantenha a janela do programa aberta** enquanto joga, pois é ela que mantém o multi-instance funcionando.

## ⚠️ O Windows bloqueou o arquivo?

Os programas ainda **não têm assinatura digital**, então o Windows pode reclamar:

- **Aviso azul do SmartScreen:** clique em **Mais informações → Executar assim mesmo**.
- **"Uma política de Controle de Aplicativo bloqueou este arquivo":** é o *Smart App Control* (ou uma política da empresa/escola). Veja as opções no `README.txt` do kit de build, ou rode o programa direto pelo código com Python.

## 🔒 Segurança e avisos

- O cookie `.ROBLOSECURITY` dá acesso total à conta. **Nunca compartilhe** os arquivos de dados nem o cookie com ninguém.
- Os dados ficam em `%APPDATA%\RbxMultiManager`.
- O programa roda 100% no seu PC e só fala com o Roblox e com o GitHub (para checar atualizações).
- Projeto **não oficial**, sem qualquer ligação com a Roblox Corporation. Use por sua conta e risco e respeite os Termos de Uso do Roblox.

## 🔄 Atualizações

Ao abrir, o programa consulta a página de Releases deste repositório. Se existir uma versão mais nova, ele avisa e baixa o arquivo certo (Setup ou Portable). Você também pode verificar em **Preferências → Atualizações → Verificar agora**.

## 🐞 Problemas e sugestões

Abra uma [Issue](https://github.com/gatosmias1/Roblox-Multi-Account-Manager/issues) descrevendo o problema, a versão do programa (aparece em *Preferências*) e a mensagem exibida.

# 🇺🇸 English

A Windows app that lets you **run several Roblox accounts at the same time** on one PC, with a clean modern interface (light/dark theme).

## ⬇️ Download

Go to **[Releases](https://github.com/gatosmias1/Roblox-Multi-Account-Manager/releases/latest)** and download **one** of these files:

| File | What it is |
|---|---|
| `Roblox-Multi-Account-Manager-Setup.exe` | **Installer.** Installs on Windows with shortcuts and an uninstaller. Per-user install (no administrator needed). |
| `Roblox-Multi-Account-Manager-Portable.exe` | **Portable.** Nothing to install: just run it from any folder or USB drive. |

Both are the same program and share the same data.

## ✨ Features

- **Multi-instance:** open as many accounts as you want at once.
- **Log in through the official website, nothing to install:** it opens Microsoft Edge (or Chrome) in a temporary window, you sign in normally, and the cookie is captured automatically.
- **Protected cookies:** encrypted with Windows (DPAPI) on this PC.
- **Games:** search by name or ID, use recent games and favorites, and set a Job ID to join a specific server.
- **Interval between accounts:** the seconds are saved automatically.
- **Account groups:** start several accounts with one click.
- **Live status:** Online, Offline or In game, refreshed quickly.
- **Nicknames and colors** to tell accounts apart.
- **Start with Windows** (optionally minimized to the tray).
- **System tray** and an **optional password** to open the app.
- **Automatic language:** English or Portuguese, based on your Windows language (you can change it in *Preferences*).
- **Automatic updates:** tells you when a new version is in Releases and installs it for you.

## 🧩 Requirements

- Windows 10 or 11 (64-bit).
- Roblox installed **from roblox.com** (not from the Microsoft Store).
- Microsoft Edge (included with Windows) or Google Chrome, only for the website login.

## 🚀 How to use

1. Open the app and click **Log in via website** (or **Add cookie**).
2. Sign in to the account in the window that opens. It closes by itself when done. Repeat for each account.
3. Tick the accounts you want to open.
4. (Optional) Type the game name or ID and, if you want, a Job ID.
5. Click **Start**. **Keep the app window open** while you play, because it is what keeps multi-instance working.

## ⚠️ Did Windows block the file?

The apps are **not code-signed yet**, so Windows may complain:

- **Blue SmartScreen warning:** click **More info → Run anyway**.
- **"An Application Control policy blocked this file":** this is *Smart App Control* (or a work/school policy). See the `README.txt` in the build kit for options, or run the app straight from source with Python.

## 🔒 Security and notes

- The `.ROBLOSECURITY` cookie gives full access to the account. **Never share** the data files or the cookie with anyone.
- Data is stored in `%APPDATA%\RbxMultiManager`.
- The app runs entirely on your PC and only talks to Roblox and to GitHub (to check for updates).
- **Unofficial** project, not affiliated with Roblox Corporation. Use at your own risk and follow the Roblox Terms of Use.

## 🔄 Updates

On startup the app checks this repository's Releases page. If a newer version exists, it tells you and downloads the right file (Setup or Portable). You can also check manually in **Preferences → Updates → Check now**.

## 🐞 Issues and suggestions

Open an [Issue](https://github.com/gatosmias1/Roblox-Multi-Account-Manager/issues) with the problem, the app version (shown in *Preferences*) and the message you see.
